# 3D Boarding Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the portfolio's decorative 2D backdrop with a WebGL scene, entered through a 2.4s camera dolly that resolves into a permanent, interaction-reactive 3D background.

**Architecture:** All timing, layout and response math lives as pure functions in `lib/scene.ts` (unit-tested without a WebGL context). `hooks/use-boarding.ts` owns capability detection and the two-phase state machine. `components/os/scene/` holds the r3f component tree, dynamically imported with `ssr: false`. The existing `backdrop.tsx` is retained as the no-WebGL fallback, and a new `sr-only` DOM mirror keeps the backdrop copy crawlable and screen-reader accessible now that it renders in the canvas.

**Tech Stack:** Next.js 16.2.12 App Router, React 19.2.4, TypeScript, Tailwind v4, three 0.185.1, @react-three/fiber 9.6.1, @react-three/drei 10.7.7, `node --test` for unit tests.

**Spec:** `docs/superpowers/specs/2026-07-29-3d-boarding-design.md` — read it before starting.

## Global Constraints

- **This project is NOT a git repository.** `git status` fails with "not a repository". Every task therefore ends in a **Gate** step (typecheck / test / lint / build) instead of a commit. Do not run `git init` — that is the user's call.
- **Read the Next.js docs before writing code.** Per `AGENTS.md`: this Next.js version has breaking changes relative to training data. Before using `next/dynamic`, read the relevant guide under `node_modules/next/dist/docs/`. Heed deprecation notices.
- **Zero border radius.** `--radius*` tokens are all `0px` in `app/globals.css`. Never introduce a rounded corner.
- **Palette is fixed.** ink `#16130F`, orange `#E33F00`, yellow `#F2C230`, paper `#E4E5DE`, window `#EEEFE9`, card `#FBFBF7`. No gradients, no new colours.
- **No new dependencies beyond these three:** `three@0.185.1`, `@react-three/fiber@9.6.1`, `@react-three/drei@10.7.7`. Specifically **no** `postprocessing`, no animation library (gsap/framer/motion). Camera easing is a `useFrame` lerp against elapsed time.
- **All copy comes from `BACKDROP` in `lib/content.ts`.** Never hardcode a display string in a scene component or in the `sr-only` mirror.
- **Windows are never conditionally unmounted.** They are hidden with `opacity`/`visibility` only. The existing SSR-for-crawlers strategy (`components/os/desktop.tsx:64-69`) must survive unchanged.
- **Test imports use explicit `.ts` extensions** (`from "./scene.ts"`) — see `lib/geometry.test.ts:4-6`. `npm test` runs `node --test 'lib/**/*.test.ts'`.
- **Test commands:**
  - `npm test` — unit tests
  - `npx tsc --noEmit` — typecheck
  - `npm run lint` — eslint
  - `npm run build` — production build
- **Canvas z-index is `z-0`.** The menu bar is `z-[500]` (`components/os/menu-bar.tsx:17`) and windows are z 100+. Never raise the canvas above them.

```ts
  assert.equal(cameraZ(0), CAM_START_Z);
  assert.equal(cameraZ(1), CAM_REST_Z);

  for (let i = 0; i <= 100; i++) {

    prev = z;

  assert.ok(Math.abs(w - h * 1.6) < 1e-9, "width must follow the aspect ratio");

  assert.ok(Math.abs(far.h - h * 2) < 1e-9);

  const vh = 1000;

  assert.ok(Math.abs(centre.x) < 1e-9, "screen centre is world x=0");
```

```ts
import { MOBILE_BREAKPOINT, WINDOW_ORDER, type WindowId } from "./windows";

// ─── camera + timing ──────────────────────────────────────────────────────
// Every beat of the intro is a constant here, never a literal in a component.

export const FOV = 55;
export const CAM_START_Z = 42;
export const CAM_REST_Z = 4;

/** Camera dolly duration. Chrome and windows land after it, per the spec's beat sheet. */
export const DOLLY_MS = 2100;
export const CHROME_MS = 2250;
export const WINDOWS_MS = 2400;
/** Kinetic headline reveal window — words land before the camera starts pushing. */
export const TYPE_MS = 550;

/** Per-frame lerp factor for every damped value in the scene. At 60fps this
 *  reaches ~95% of target in ~19 frames (~320ms), which is what makes the skip
 *  gesture feel like the specified 350ms ease without any extra machinery. */
export const DAMP = 0.15;

export const BOOT_KEY = "bm.boarded";

export function easeOutExpo(t: number): number {
  if (t <= 0) return 0;
  if (t >= 1) return 1;
  return 1 - Math.pow(2, -10 * t);
}

/** Camera depth at normalised intro progress `t`. Clamped at both ends so a
 *  late or early frame can never overshoot the rest framing. */
export function cameraZ(t: number): number {
  return CAM_START_Z + (CAM_REST_Z - CAM_START_Z) * easeOutExpo(t);
}

// ─── screen ↔ world projection ────────────────────────────────────────────
// The spec requires scene copy to land at the same screen position the DOM
// backdrop uses today. That is only exact if we project through the real
// frustum, so these two functions are the single source of scene layout.

/** Visible world extent at `dist` units from the camera. */
export function worldSize(vw: number, vh: number, dist: number): { w: number; h: number } {
  const h = 2 * dist * Math.tan((FOV * Math.PI) / 360);
  return { w: h * (vw / vh), h };
}

/** Screen pixel → world position on the plane `dist` units from the camera.
 *  Note y flips: screen y grows downward, world y grows upward. */
export function pxToWorld(
  px: number,
  py: number,
  vw: number,
  vh: number,
  dist: number,
): { x: number; y: number } {
  const { w, h } = worldSize(vw, vh, dist);
  return { x: (px / vw - 0.5) * w, y: (0.5 - py / vh) * h };
}

// ─── capability tiers ─────────────────────────────────────────────────────

export type Tier = "full" | "mobile" | "reduced" | "none";

/** Order matters and is specified: no WebGL beats reduced-motion beats width. */
export function detectTier(width: number, hasWebGL: boolean, reduced: boolean): Tier {
  if (!hasWebGL) return "none";
  if (reduced) return "reduced";
  return width < MOBILE_BREAKPOINT ? "mobile" : "full";
}

// ─── phase machine ────────────────────────────────────────────────────────

export type Phase = "dolly" | "rest";

/** `forced` is the `?boot=1` dev hatch. It overrides the session flag but is
 *  deliberately powerless against reduced-motion — a debug convenience must
 *  never animate for someone who asked for no animation. */
export function initialPhase(tier: Tier, booted: boolean, forced: boolean): Phase {
  if (tier !== "full") return "rest";
  return booted && !forced ? "rest" : "dolly";
}

// ─── interaction response ─────────────────────────────────────────────────

export type SceneInput = {
  openCount: number;
  focusedId: WindowId | null;
  hoveredId: WindowId | null;
  /** Deliberately a boolean, not a position — a positional prop would push new
   *  props into the canvas tree on every pointermove of a window drag. */
  dragging: boolean;
};

export const DOLLY_PER_WINDOW = 0.4;
/** Hard clamp so five open windows cannot walk the camera into the geometry. */
export const DOLLY_MAX = 1.6;
export const SLAB_LEAN_DEG = 3;

export function sceneResponse(input: SceneInput): {
  camZ: number;
  slabLean: number;
  waveIndex: number;
} {
  return {
    camZ: CAM_REST_Z - Math.min(input.openCount * DOLLY_PER_WINDOW, DOLLY_MAX),
    slabLean: input.dragging ? SLAB_LEAN_DEG : 0,
    waveIndex: input.hoveredId ? WINDOW_ORDER.indexOf(input.hoveredId) : -1,
  };
}

// ─── scene layout ─────────────────────────────────────────────────────────
// Positions are viewport fractions measured off the current 2D backdrop at a
// 1440×900 reference, so the 3D scene reads as the same composition. `dist` is
// distance from the REST camera, so a larger dist sits further back.
//
// Nothing sits closer to the camera than dist=3. The camera travels 42 → 4 and
// never passes an object: the "whip past" read comes from near-plane objects
// sweeping out through the frame edges under perspective, not from the camera
// physically overtaking them.

const DEG = Math.PI / 180;

export type Slab = {
  /** viewport fraction of the shape's centre */
  fx: number;
  fy: number;
  /** px at the 1440×900 reference */
  size: number;
  /** thickness in world units */
  depth: number;
  dist: number;
  rot: number;
  color: string;
  opacity: number;
  kind: "solid" | "edges";
  roughness: number;
};

export const SLABS: readonly Slab[] = [
  // 260px outlined square (backdrop.tsx: right 6vw / bottom 6vh / rotate 12deg)
  {
    fx: 0.85, fy: 0.796, size: 260, depth: 0.12, dist: 3.4, rot: 12 * DEG,
    color: "#16130F", opacity: 0.55, kind: "edges", roughness: 1,
  },
  // 160px yellow block (right 12vw / bottom 12vh / rotate -6deg). The one
  // surface in the scene with a highlight — spec §8.
  {
    fx: 0.824, fy: 0.791, size: 160, depth: 0.3, dist: 3.6, rot: -6 * DEG,
    color: "#F2C230", opacity: 1, kind: "solid", roughness: 0.3,
  },
  // 66px ink block (left 24% / bottom 16%)
  {
    fx: 0.263, fy: 0.803, size: 66, depth: 0.22, dist: 3.2, rot: 0,
    color: "#16130F", opacity: 0.12, kind: "solid", roughness: 1,
  },
  // 22px orange chip (left 46% / top 18%)
  {
    fx: 0.468, fy: 0.192, size: 22, depth: 0.18, dist: 3, rot: 0,
    color: "#E33F00", opacity: 0.4, kind: "solid", roughness: 1,
  },
];

/** Rotated orange band + its rule (backdrop.tsx lines 35–36). */
export const BAND = {
  dist: 12,
  rot: -9 * DEG,
  /** fraction of the frustum width at `dist` */
  widthScale: 1.3,
  heightPx: 210,
  rulePx: 3,
  color: "#E33F00",
  bandOpacity: 0.08,
  ruleOpacity: 0.2,
} as const;

/** Outlined BM. Flat SDF text with a stroke, matching the current design's
 *  transparent-fill `WebkitTextStroke` treatment.
 *  ponytail: flat, not extruded. Ceiling — it will not catch the key light or
 *  show thickness as the camera closes on it. Upgrade path is drei `Text3D`
 *  plus a facetype.js JSON conversion of Space Grotesk. */
export const MONOGRAM = {
  dist: 7,
  /** fraction of frustum height */
  sizeScale: 0.4,
  fx: 0.86,
  fy: 0.24,
  strokeOpacity: 0.1,
} as const;

/** Copy renders on the plane at exactly the rest camera distance, so pxToWorld
 *  is pixel-exact against the DOM positions backdrop.tsx uses today. */
export const COPY_Z = CAM_REST_Z;

export const GRID = {
  y: -1.4,
  /** world extent along x and z */
  spanX: 40,
  spanZ: 46,
  /** points per axis, per tier */
  divisionsFull: 60,
  divisionsMobile: 24,
  color: "#16130F",
  opacity: 0.18,
  dotSize: 0.03,
  /** ripple amplitude in world units, and how fast it decays with distance */
```

```tsx
"use client";

import { useMemo, useRef } from "react";
import { useFrame } from "@react-three/fiber";
import * as THREE from "three";

import { GRID, type Tier } from "@/lib/scene";

export type GridFloorProps = {
  tier: Tier;
  /** Dock slot index to ripple from, or -1 for no ripple. */
  waveIndex: number;
};

/** The receding dot grid — the 3D counterpart of backdrop.tsx's DOT_GRID
 *  radial-gradient. Points rather than lines because the 2D design is dots. */
export function GridFloor({ tier, waveIndex }: GridFloorProps) {
  const n = tier === "full" ? GRID.divisionsFull : GRID.divisionsMobile;
  const points = useRef<THREE.Points>(null);

  /** Base positions, plus the flat x/z arrays the ripple reads each frame. */
  const { geometry, base } = useMemo(() => {
    const pos = new Float32Array(n * n * 3);
    const base = new Float32Array(n * n * 2);
    let i = 0;
    for (let ix = 0; ix < n; ix++) {
      for (let iz = 0; iz < n; iz++) {
        const x = (ix / (n - 1) - 0.5) * GRID.spanX;
        // z runs away from the camera so the camera flies out over the grid
        const z = -(iz / (n - 1)) * GRID.spanZ;
        pos[i * 3] = x;
        pos[i * 3 + 1] = 0;
        pos[i * 3 + 2] = z;
        base[i * 2] = x;
        base[i * 2 + 1] = z;
        i++;
      }
    }
    const g = new THREE.BufferGeometry();
    g.setAttribute("position", new THREE.BufferAttribute(pos, 3));
    return { geometry: g, base };
  }, [n]);

  /** Ripple origin in world x, derived from the hovered dock slot (0..4). */
  const originX = useMemo(() => {
    if (waveIndex < 0) return null;
    return (waveIndex / 4 - 0.5) * GRID.spanX * 0.5;
  }, [waveIndex]);

  useFrame((state) => {
    const mesh = points.current;
    if (!mesh) return;
    const attr = mesh.geometry.getAttribute("position") as THREE.BufferAttribute;
    const t = state.clock.elapsedTime;
    const count = attr.count;

    if (originX === null) {
      // settle flat
      let dirty = false;
      for (let i = 0; i < count; i++) {
        const y = attr.getY(i);
        if (Math.abs(y) > 0.0005) {
          attr.setY(i, y * (1 - GRID.waveFalloff));
          dirty = true;
        }
      }
      if (dirty) attr.needsUpdate = true;
      return;
    }

    for (let i = 0; i < count; i++) {
      const dx = base[i * 2] - originX;
      const dz = base[i * 2 + 1];
      const d = Math.sqrt(dx * dx + dz * dz);
      const decay = Math.exp(-d * GRID.waveFalloff);
      attr.setY(i, Math.sin(d - t * GRID.waveSpeed) * GRID.waveAmp * decay);
    }
    attr.needsUpdate = true;
  });

  return (
    <points ref={points} geometry={geometry} position={[0, GRID.y, 0]}>
      <pointsMaterial
        color={GRID.color}
        size={GRID.dotSize}
        sizeAttenuation
        transparent
        opacity={GRID.opacity}
        depthWrite={false}
      />
    </points>
  );
}
```

- [ ] **Step 1: Write the hook**

Create `hooks/use-boarding.ts`:

```ts
"use client";

import { useCallback, useEffect, useState } from "react";

import {
  BOOT_KEY,
  CHROME_MS,
  DOLLY_MS,
  WINDOWS_MS,
  detectTier,
  initialPhase,
  type Phase,
  type Tier,
} from "@/lib/scene";

function hasWebGL(): boolean {
  try {
    const c = document.createElement("canvas");
    return !!(c.getContext("webgl2") || c.getContext("webgl"));
  } catch {
    return false;
  }
}

export type Boarding = {
  tier: Tier;
  phase: Phase;
  /** performance.now() at intro start, or null if there is no intro. The camera
   *  reads this inside useFrame rather than receiving per-frame React state. */
  startedAt: number | null;
  chromeVisible: boolean;
  windowsVisible: boolean;
  skip: () => void;
};

/** Capability detection and the two-phase intro machine.
 *
 *  Detection runs in an effect, so the first (server and hydration) render is
 *  always tier "none" / phase "rest". That is deliberate: it matches what the
 *  server can know, so there is no hydration mismatch, and it means the
 *  no-WebGL fallback is what renders if JS never runs. */
export function useBoarding(): Boarding {
  const [state, setState] = useState<{ tier: Tier; phase: Phase; startedAt: number | null }>({
    tier: "none",
    phase: "rest",
    startedAt: null,
  });
  const [chromeVisible, setChromeVisible] = useState(true);
  const [windowsVisible, setWindowsVisible] = useState(true);

  useEffect(() => {
    const reduced = window.matchMedia("(prefers-reduced-motion: reduce)").matches;
    const tier = detectTier(window.innerWidth, hasWebGL(), reduced);
    const booted = sessionStorage.getItem(BOOT_KEY) === "1";
    const forced = new URLSearchParams(window.location.search).get("boot") === "1";
    const phase = initialPhase(tier, booted, forced);

    if (phase === "rest") {
      sessionStorage.setItem(BOOT_KEY, "1");
      setState({ tier, phase, startedAt: null });
      return;
    }

    setChromeVisible(false);
    setWindowsVisible(false);
    setState({ tier, phase, startedAt: performance.now() });
  }, []);

  /** Ends the intro from any cause — elapse or skip — and is idempotent. */
  const land = useCallback(() => {
    sessionStorage.setItem(BOOT_KEY, "1");
    setState((s) => (s.phase === "rest" ? s : { ...s, phase: "rest" }));
    setChromeVisible(true);
    setWindowsVisible(true);
  }, []);

  // Natural end of the intro: three timers on the spec's beat sheet.
  useEffect(() => {
    if (state.phase !== "dolly") return;
    const t1 = setTimeout(() => setChromeVisible(true), CHROME_MS);
    const t2 = setTimeout(() => setWindowsVisible(true), WINDOWS_MS);
    const t3 = setTimeout(land, DOLLY_MS);
    return () => {
      clearTimeout(t1);
      clearTimeout(t2);
      clearTimeout(t3);
    };
  }, [state.phase, land]);

  // Skip on any deliberate input. Capture phase so nothing underneath handles
  // the event first, and { once: true } so the listeners retire themselves.
  useEffect(() => {
    if (state.phase !== "dolly") return;
    const opts = { capture: true, once: true } as const;
```

- [ ] **Step 1: Drive headlineProgress from the intro clock**

In `components/os/scene/scene.tsx`, replace the static `<SceneCopy headlineProgress={1} />` with a small driver component that keeps the per-frame value out of React state:

```tsx
function CopyDriver({ phase, startedAt }: { phase: Phase; startedAt: number | null }) {
  const progress = useRef(phase === "dolly" ? 0 : 1);
  const [, force] = useState(0);

  useFrame(() => {
    if (phase !== "dolly" || startedAt === null) {
      if (progress.current !== 1) {
        progress.current = 1;
        force((n) => n + 1);
      }
      return;
    }
    const t = (performance.now() - startedAt) / DOLLY_MS;
    const next = Math.min(easeOutExpo(Math.max(t, 0)), 1);
    // Quantise to ~60 steps: troika re-lays out text on prop changes, so
    // feeding it a fresh float every frame is the expensive path.
    const q = Math.round(next * 60) / 60;
    if (q !== progress.current) {
      progress.current = q;
      force((n) => n + 1);
    }
  });

  return <SceneCopy headlineProgress={progress.current} startedAt={startedAt} phase={phase} />;
}
```

Render `<CopyDriver phase={phase} startedAt={startedAt} />` in place of the old line. Import `useRef`, `useState`, and `easeOutExpo`, `TYPE_MS`.

- [ ] **Step 2: Add the mask reveal**

troika supports `clipRect`, which is a real mask — animating its edge wipes the glyphs into view rather than fading them.

**Use one `clipRect` sweeping across the whole headline, not one per word.** Splitting into per-word `<Text>` components means troika stops wrapping the block for you: every word becomes its own layout at the same origin, and you would have to measure each one via `onSync`'s `textRenderInfo.blockBounds` and run your own x-cursor and wrap logic. That is a text layout engine, written to stagger five words. The single sweep reads as the same effect and is a prop.

In `components/os/scene/copy.tsx`, extend the props:

```tsx
export type SceneCopyProps = {
  headlineProgress: number;
  startedAt: number | null;
  phase: Phase;
};
```

Add the reveal maths above the returned JSX:

```tsx
  /** Reveal progress 0..1 across TYPE_MS, before the camera push begins. */
  const reveal =
    phase === "dolly" && startedAt !== null
      ? Math.min(Math.max((performance.now() - startedAt) / TYPE_MS, 0), 1)
      : 1;

  /** Tracking tightens -0.06 -> -0.035 across the reveal.
   *  ponytail: quantised to 6 steps, not animated per frame. Ceiling — troika
   *  re-lays out the whole text block on every letterSpacing change, so a 60fps
   *  sweep costs a full layout per frame for a change nobody can see at that
   *  resolution. Upgrade path is a custom shader that offsets glyph positions. */
  const trackStep = Math.round(reveal * 6) / 6;
  const tracking = -0.06 + (0.06 - 0.035) * trackStep;
```

Then replace the headline `<Text>` with the masked version. `clipRect` is `[minX, minY, maxX, maxY]` in the text's own local units, so sweeping `minY` upward from below the block uncovers it bottom-to-top:

```tsx

  const blockW = size38 * 24;
  /** Tall enough to cover the wrapped block at any viewport. */
  const blockH = size38 * 1.05 * 4;

  const clip: [number, number, number, number] = [
    -blockW,
    -blockH,
    blockW,
    // maxY sweeps from the block's bottom to its top across the reveal
    -blockH + blockH * 2 * reveal,
  ];
```

```tsx
      <group position={[hlX, hlY, 0]} scale={hlScale}>
        <Text
          font={SANS}
          fontSize={size38}
          letterSpacing={tracking}
          maxWidth={blockW}
          lineHeight={1.05}
          anchorX={p > 0.5 ? "left" : "center"}
          anchorY={p > 0.5 ? "top" : "middle"}
          color="#16130F"
          fillOpacity={0.17 + (1 - p) * 0.5}
          clipRect={clip}
        >
          {BACKDROP.headline}
        </Text>
      </group>
```

Note `fillOpacity` interpolates too: the headline is near-solid during its hero moment and settles to the backdrop's dimmed `0.17`, so it reads as type first and scenery second.

**Optional upgrade, only if the single sweep looks flat:** stagger per word by splitting on spaces and laying each out with an `onSync` x-cursor. That is a text layout engine written to stagger five words — do not start there, and report it if you go there.

## Deviations to report

The plan makes three engineering calls that trade specified behaviour for cost. Each is marked with a `ponytail:` comment in the code naming its ceiling. Report whether each held:

1. **Flat monogram, not extruded** (`lib/scene.ts`, `MONOGRAM`) — avoids a facetype.js build step. Upgrade path is drei `Text3D`.
2. **Quantised tracking animation** (`copy.tsx`) — 6 steps instead of per-frame, because troika re-lays out on every `letterSpacing` change. Upgrade path is a glyph-offset shader.
3. **No bloom** (spec §8) — deliberate, not a shortcut: bloom needs dark pixels and the paper background is `#E4E5DE`. Contact shadows and the rim light carry the material quality instead.
4. **Whole-headline mask sweep, not per-word stagger** (`copy.tsx`, Task 7) — a per-word reveal requires reimplementing text wrapping. Report if the single sweep reads flat enough to need the upgrade.
